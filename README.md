<h1>Finance Tracker CLI (Java Capstone)</h1>
A clean, command-line Java application to track income and expenses.

![Screenshot 2025-05-02 010651](https://github.com/user-attachments/assets/e65e61ea-de6f-45f6-abd0-9b5e7c433f39)

## ✅ Features

📌 CLI Menu with clear options  
💰 Add **Deposits** (income)  
🧾 Add **Payments** (expenses)  
📖 View full **Ledger**  
🗂 Filter by:
- Deposits only
- Payments only  

📊 Generate **Reports**:
- 📅 Month-To-Date
- ⏳ Previous Month
- 📆 Year-To-Date
- 🕰 Previous Year
- 🔍 Search by Vendor
- 🧠 **Custom Search** (Challenge Feature): date range, vendor, and description filters
